# Еда — Лиза и Олег

Сайт: https://mopilek96-ai.github.io/eda/

Рецепты в виде таблиц (как в Google-таблице «Списки продуктов»), меню на неделю → список покупок, дневник калорий для каждого, база продуктов.

- Данные: Supabase-проект `srpske-reci` (общий с карточками), таблицы `products`, `recipes`, `diary`, `kv` — схема в `supabase/schema.sql`.
- Первый запуск переносит данные из `data/seed.json` (выгрузка таблицы 17.11.2026).
- ИИ (фото этикетки, поиск блюда в интернете): Edge Function `supabase/functions/ai`, ключ в секрете `ANTHROPIC_API_KEY`. Промпты взяты из бота `food-bot`.
- Расчёт: КБЖУ продукта на 100 г × граммы → сумма = «всего на блюдо»; «в 100 г» = сумма ÷ вес готового блюда × 100; порция = «в 100 г» × граммы порции ÷ 100. Если вес готового не указан — делим на сумму сырых граммов. Для блюд «в штуках» — сумма ÷ число штук.
